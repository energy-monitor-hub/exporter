# Безпека

[English version](SECURITY.md)

Це хобі-проєкт без комерційної мети, наданий **як є, без гарантій** (див. [LICENSE](LICENSE)). Повідомлення вітаються й опрацьовуються, наскільки вистачає часу.

## Як повідомити про вразливість

Будь ласка, **не відкривай публічний issue** про проблему безпеки. Скористайся приватним повідомленням GitHub: вкладка **Security** репозиторію, **Report a vulnerability**. Опиши, що вражено, як відтворити і що отримує нападник. Підтримуються лише гілка `main` і останній реліз.

## Модель безпеки експортера

| Що | Як це влаштовано |
| --- | --- |
| Пароль EcoFlow | Надсилається лише в API входу EcoFlow. Зберігається або в твоєму `.env`, або зашифрованим (AES-256-GCM) у `/data/credentials.json`; ключ тримає твій проєкт Supabase, окремо для кожного експортера, і видаляє, коли ти експортер відкликаєш. Див. [README, «Куди йдуть твої облікові дані»](README.uk.md#куди-йдуть-твої-облікові-дані). |
| Доступ до Supabase | Експортер входить як **ти** через OAuth 2.1 сервер Supabase (PKCE, loopback-redirect): anon-ключ плюс твій токен, ніколи не `service_role`. Токени в `/data/oauth.json` (права 0600). Відкликати експортер — на сторінці дашборда **«Експортери»**. |
| Локальна сторінка стану | Слухає (а в Docker опублікована) лише на `127.0.0.1`; відповідає лише на імена `localhost` / IP (захист від DNS rebinding, `UI_ALLOWED_HOSTS` для інших); форма облікових даних і кнопки зразків працюють лише через loopback-ім'я, а нативно ще й лише для loopback-адреси клієнта, тож підроблений заголовок `Host` з локальної мережі не пройде. |
| Пакети декодера і список релізів | Лише дані, ніколи не код; підписи Ed25519 перевіряються ключами з `src/packs/verify.ts` (плюс `DECODER_PUBLIC_KEYS`). |
| Оновлення | Експортер ніколи не отримує сокет Docker. Його має окремий контейнер-оновлювач: без опублікованого порту, відповідає лише контейнеру експортера, встановлює лише digest з підписаного списку релізів, чиє походження збірки в GitHub (Sigstore) відповідає тегу релізу, і відкочує версію, яка не запустилася; файлова система лише для читання, без capabilities, без `.env`. Див. [docs/uk/UPDATES.md](docs/uk/UPDATES.md). |
| Дані, якими ділишся | Перепис моделей і зразки — лише за згодою, показаною на сторінці стану; серійні номери, id акаунта й e-mail маскуються до того, як щось покине машину, а завантаження блокується, якщо ідентифікатор все одно знайдено. |
| Збірки | GitHub Actions закріплені за SHA коміту, за замовчуванням `contents: read`. Образи й бінарники мають підписаний build provenance attestation (`gh attestation verify`). |
| Залежності | Лише точні версії, 7-денний карантин для нових npm-релізів, install-скрипти за списком дозволених, образи за digest (`make deps-check`). |

Відомі межі: поки експортер **не** відкликано, той, хто скопіює весь том `/data`, має й `oauth.json` і може отримати ключ; шкідлива програма на тій самій машині може прочитати пам'ять процесу.
