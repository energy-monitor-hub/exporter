# Decoder packs

Device models as data, read by `src/packs/interpreter.ts`: see [docs/DECODER_PACKS.md](../docs/DECODER_PACKS.md)
([Українська](../docs/uk/DECODER_PACKS.md)).

The `proto` descriptors are derived from the message definitions of
[foxthefox/ioBroker.ecoflow-mqtt](https://github.com/foxthefox/ioBroker.ecoflow-mqtt) (MIT, see
`src/proto/LICENSE-ioBroker`).
